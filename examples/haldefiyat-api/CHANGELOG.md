# Public API Changelog

## 1.0.0-docs — 2026-07-27

- Mevcut `/api/v1` davranışı için ilk bağımsız public OpenAPI sözleşmesi eklendi.
- Fiyat listesi, ürün geçmişi, haftalık özet, kaynak sağlığı ve endeks
  endpoint'leri örnek pakete alındı.
- Canlı yanıt biçimi `{ items, meta }` olarak belgelendi.
- Node.js istemcisi, Jupyter notebook ve Postman collection eklendi.
- Breaking-change, deprecation ve 90 günlük sunset politikası yayımlandı.

Bu kayıt API runtime'ında breaking change yapmaz; mevcut davranışı belgeler.
